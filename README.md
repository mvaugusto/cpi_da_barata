A CPI DA BARATA: Aprendendo SQL no AWS Athena E resolvendo uma fraude histórica !

Bem-vindos à "CPI da Barata"! Neste hands-on, nós fomos acionados pelo departamento de Compliance do Folclore Brasileiro para auditar um suposto caso (escândalo) de fraude de inventário que já dura décadas.

A Dona Barata diz que tem 7 saias de filó... Mas será que os registros inventariados no banco de dados oficial concorda com ela? 🪳🔎

"Ingual na firma" você vai plugar no AWS Athena e usar SQL puro para investigar no Data Lake ou Data Mesh e evidenciar com dados, se é Mentira ou Verdade da Barata .

Neste lab prático, você vai aprender do zero:

✅ Como criar tabelas externas apontando para o Amazon S3 (Data Lake)
✅ Como Inserir dados em tabelas INSERT INTO
✅ A estrutura fundamental da query SELECT
✅ Como filtrar evidências usando a cláusula WHERE
✅ Como auditar volumes de dados usando a função COUNT
